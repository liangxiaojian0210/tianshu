## 需求清单

| # | 需求 | 来源 |
|---|---|---|
| 1 | 百分比承诺隐藏负载依赖：同一实现，空算子基线下差值占比 ~25%，算子加到 ~1.5µs 后 1.65%——承诺语义必须显式包含负载 | 2026-09-17 负载探针实测（r2-rounds/heavy*） |
| 2 | 空算子微基准下纯百分比物理不可达（51ns 基线的 1% = 0.51ns < 一条分支指令） | ADR-0032 D5 预算数学 |
| 3 | 判决报告需要稳定可追踪的工程量（百分比随负载漂移，无法作为回炉对号依据） | 回炉第二轮复盘 |

## 决策

### D1：主承诺 —— 加性模型（负载无关，可直接验收）

编译产物相对**同语义手写装配**的额外延迟是加性的：

```
diff ≤ F + k × 跳数 + m × 扇出支数
```

| 常数 | 预算 | 语义 |
|---|---|---|
| k（每跳） | ≤ 2ns | 当前架构（类型擦除 IR 携带算子）的派发地板；随 ADR-0035 落地重论证 |
| F（每消息） | ≤ 20ns | 入口固定残余（入口特化后残项，归因中） |
| m（每扇出支） | 待定 | fan-out 分支机器，待归因后定值 |

验收方式：空算子五形状微基准（对抗极端）在协议 v2 下取**同轮差值**直接量取分解；加性由负载探针保证（见 D4）。

### D2：从承诺 —— 负载条件化百分比（适用域显式）

当每消息算子工作量 **W ≥ (F + k × hops) / 1%** 时，端到端 P99 差 <1% 成立。

- **W 的实测口径**：每消息所有算子体执行时间之和；测量用空算子基线差值法（加重前后金标准之差）或算子内直接计时。
- **W 的声明口径**：DSL 已有的 `with_wcet` 为 W 上界——实测 W 超声明 WCET 应在加载期 SLA 校验中报告（与 ADR-0029 预算体系衔接，本篇不实现）。

### D3：判决报告双轨

百分比（用户口径）与 (F, k, m) 分解（工程口径）同时报告；§6.1 基线表附各形状分解。回炉以常数对号，不以百分比对号。

### D4：加性实证

负载探针（2026-09-17，TI_HEAVY 受控注入依赖链计算，证据 `r2-rounds/heavy{300,3000}`）：long 形状金标准 642 → 1723 → 11472ns（×18），**差值绝对量恒定 150-190ns（漂移带内）**，占比 25% → 9.9% → 1.65%。推论：声明层开销无乘性成分；且与消息字节大小无关（字节路径 dispatch/fill/try_fetch 两侧为同一份代码）。

### D5：现状与压缩路径

实测（协议 v2 同轮差值）：k ≈ 6-8ns/跳（fn 间接 2-5 + 收件环原子协议 2-3）、F ≈ 80-100ns（未归因，疑含装置效应）、m ≈ 40-45ns/支 → **H2 在 v3 语义下仍 FAIL**。压缩路径：ADR-0035（算子直呼，砍 fn 间接）→ 单写者免原子槽（后继，砍收件环协议）。

## 后果

- 正面：承诺诚实（适用域显式）、可验收（常数在对抗极端基准上直接量取）、与目标域对齐（感知帧级 W 下 1% 自动成立，当前常数约需 W ≥ 20µs/消息，k/F 压缩后降至 ~10µs）。
- 负面：公开措辞从单一数字变为两层表述，简洁性下降；F/m 预算在归因完成前为暂定值。
- 修订记录：取代 ADR-0032 D5 的 `max(1%, 2ns/跳)` 单式条款（该式为本篇 D1+D2 的前身；2ns/跳保留为 k 的预算值）。
